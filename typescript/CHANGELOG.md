# Changelog

## 0.1.0 (8 November 2026)

First version: `Namu` with `speech`, `transcribe`, `translate`, `converse`, `usage`, `voices` and `models`; types for
every response; one error class per status; retries for network errors, `rate_limited` and 502/503/504; timeouts; the
`NAMU_API_KEY` and `NAMU_BASE_URL` environment variables. No runtime dependencies; Node 18+, Deno, Bun, Workers.
