# Changelog

## 0.1.0 (unreleased)

First version: `Namu` with `speech`, `transcribe`, `translate`, `converse`, `usage`, `voices` and `models`; typed
responses; one error class per status; retries for network errors, `rate_limited` and 502/503/504; timeouts; the
`NAMU_API_KEY` and `NAMU_BASE_URL` environment variables.
